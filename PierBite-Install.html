Install PierBite

Put PierBite on your phone just like an app. Open it with one tap for pier conditions, water temperature, wind, webcams, photos, and more.

PierBite is already running as an installed app.

Android

Chrome may show the green Install PierBite button above. If it does not, use Chrome's menu.

  1. Open this page in Chrome.
  2. Tap the three-dot menu.
  3. Choose Install app or Add to Home screen.
  4. Confirm the installation.

iPhone / iPad

Apple uses Safari's Add to Home Screen feature.

  1. Open this page in Safari.
  2. Tap the Share button.
  3. Choose Add to Home Screen.
  4. Tap Add.
Installing PierBite does not create a separate set of information. The installed app uses the same PierBite live data and photo information used by the PierBite website.
