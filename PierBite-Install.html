Install PierBite

Put PierBite on your phone or computer. Open it with one tap for pier conditions, water temperature, wind, webcams, photos, and more.

Show installation steps

Choose your device below. When your browser offers installation, an Install PierBite button will appear here.

Choose your device

Android

Chrome may show the green Install PierBite button above. If it does not, use Chrome's menu.

  1. Open this page in Chrome.
  2. Tap the three-dot menu.
  3. Choose Install app or Add to Home screen.
  4. Confirm, then open the PierBite icon on your home screen.

iPhone / iPad

Use Safari's Add to Home Screen option.

  1. Open this page in Safari.
  2. Tap Share. In some Safari layouts, open the page menu first.
  3. Choose Add to Home Screen.
  4. If shown, switch on Open as Web App, then tap Add.

Computer

Use Chrome or Microsoft Edge on your computer.

  1. Open this page in Chrome or Edge.
  2. Click Install PierBite above if it appears, or look for the install icon in the address bar.
  3. If needed, open the browser menu and find the option to install this page as an app.
  4. Confirm, then open PierBite from your computer's app list.
PierBite is free to install and use. An internet connection is needed for current conditions, photos, and webcams. If you opened this link inside Facebook or another app, open it in Safari, Chrome, or Edge to install. Already installed? Open the PierBite icon on your home screen or computer.
